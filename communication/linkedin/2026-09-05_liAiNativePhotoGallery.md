OuEstCharlie Woof, the AI Native Photo Gallery for Claude and other AI 
(weekend post)

🐶 Woof started with the idea to get independent of cloud providers and fully control the photo library assets (photos and metadata). AI-assisted coding is a facilitator. However AI also redefines user interaction.

That is why Woof has pivoted to become an AI native photo gallery for personal photo management. It means a gallery that integrates and leverages the AI harnesses and agents capabilities from the ground up - not a vibe-coded Google Photo clone.

Woof plugs directly into your AI assistant's conversation, guiding the conversational agent for the photo management tasks:
🔎  Search for photos
🖼️  Retrieve and browse
🧹  Sort and enrich metadata

The monolithic web app is gone, it is deconstructed:
🔎 Complicated tasks like Search or Indexing are delegated to MCP wrapped services
🖼️ Rich user interactions like Browsing or viewing photos require a specific user interface, that's the purpose of MCP Apps
🧹 Complex and user specific workflows are templated through text and code Skills

The tutorial section of the blog is showcasing photo sort & enrich using Strava activity log or clustering photos. 🔗 See the link in 1st comment  

We are almost ready for version 1, final testing is ongoing. Woof now supports most photo formats, MP4 and MOV video containers. It is now compatible with the main desktop harnesses with MCP Apps: Claude Chat & CoWork, VSCode and Goose.

Want to try it? Follow the tutorial link, install the MCP server and skills and get ready for a new experience of the digital photo gallery!
