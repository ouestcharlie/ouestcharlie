# Woof MCP is almost ready for version 1.0
(weekend post)

Woof is part of the OuEstCharlie framework — it brings a photo gallery directly into Claude Desktop and other AI assistants that support local MCP servers.

Most MCP servers dealing with personal photos are just wrappers around existing apps, limited to managing metadata like albums and ratings. Woof goes further: it has its own backend index and a #McpApp interface for searching and browsing photos right inside the host — no tab switching, no separate app.

A lot has changed since the last update in April.

The gallery now handles large libraries thanks to a revamped index built on @LanceDB, with full-text search across photo descriptions and proper pagination for navigating big result sets. And it still holds to its core promises:
- Your privacy stays yours — only a subset of metadata is ever shared with the host
- Your metadata stays with your photos — stored as standard XMP, compatible with #Lightroom, #Darktable, and the broader ecosystem

I'm still looking for beta testers on Windows, Ubuntu, or macOS — and always happy to welcome code contributors, honest feedback, or a ⭐ on GitHub.
