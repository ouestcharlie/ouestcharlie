# Woof MCP is almost ready for version 1.0
(weekend post)

Woof, as part of the OuEstCharlie framework, provides a photo gallery directly in Claude Desktop (and other AI assistants supporting local MCP servers).

Most MCP servers dealing with personal photos are only wrappers to existing galleries and only manage metadata (albums, ratings...). But Woof has its own backend index and #McpApp user interface allowing for photo search and browsing directly in the host (Claude Desktop).


The Woof MCP App gallery has been a long way since last announcement in April and is now almost ready for version 1.0.

It supports large photo libraries with a revamped index based on rock solid @LanceDB, including full text search of photo descriptions, paging done right to browse through large query results and still the promise to:
- Protect your privacy, only part of the metadata is shared with the host
- Keep your metadata with your photo, based on the standard XMP (also supported by Adobe #Lightroom, #Darktable)

I am still looking for beta testers on Windows, Ubuntu or MacOs and also for kind critics, stars on Github, hands-on coders to support the project.
